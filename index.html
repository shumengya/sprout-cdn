字体用法

@font-face {
  font-family: 'LXGWWenKaiMono';
  src: url('https://sprout-cdn.pages.dev/fonts/LXGWWenKaiMono-Regular.woff2') format('woff2');
  font-weight: 400;
}
body { font-family: 'LXGWWenKaiMono', monospace; }
